# Wayne’s Customs Automotive and Towing
Original automotive brand and private website concept. React 19, TypeScript and Next.js App Router conventions, deployed with Vinext on Sites / Cloudflare Workers.

## Run
Install Node 22.13+, install dependencies, then `npm run dev`. Validate with `npx tsc --noEmit` and `npm run build`.

## Site
Homepage, three detailed service pages, and a local-only request planner. Hero uses a high-quality 3D-rendered image with restrained pointer-responsive movement; it is not a real-time 3D vehicle configurator. CSS respects reduced motion.

## Business facts and launch
Only the business name and automotive/towing industry were provided. Copy is an original proposed brand direction. Do not interpret it as verification of service scope, certifications, opening hours, location, prices, coverage, or availability. Confirm all before public launch. No invented contact information, reviews or response-time promises.

The planner keeps input in React memory, creates local notes, and supports copying or downloading them. No request is sent, no booking is confirmed and no truck is dispatched. Connect verified business contact channels before launch.

## SEO and answer discovery
Unique descriptive metadata for every route, semantic headings, readable service explanations, visible FAQs with matching FAQPage JSON-LD, image descriptions and llms.txt. Owner-private preview is intentionally noindex with robots.txt blocking all crawlers. Add verified address, phone, opening hours, geography, LocalBusiness schema and production sitemap when the real business details are supplied. Do not invent location pages or promise rankings, rich results, or AI citations.

## Assets and identity
Custom generated logo, 3D-style hero, towing, workshop and wheel photography in public/assets. Images are illustrative and do not depict verified company facilities, staff, vehicles or completed projects. Generated assets are not claims of trademark clearance. Editable favicon geometry is in public/favicon.svg.

TypeScript and production build are the available checks. Browser visual QA and Lighthouse are unavailable in this environment.
