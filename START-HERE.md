# Wayne’s Customs — Complete Codebase

Includes the latest deployed source, custom vector logo, generated logo concept, automotive imagery, self-hosted display font and license, pages, components, styling, dependency lockfile, configuration and documentation.

## Run locally
1. Install Node.js 22.13 or newer.
2. Open a terminal in this folder and run `npm install`.
3. Run `npm run dev` and open the URL shown in the terminal.
4. Run `npm run build` for a production build.

Built with React 19 and Next.js App Router conventions through Vinext for Sites / Cloudflare Workers. Other hosting platforms may require configuration changes. See README.md.

## Before public launch
Confirm phone, address, hours, service area, services and the inquiry destination. The request planner only creates local notes; it does not submit requests or dispatch a tow truck. Indexing is intentionally disabled for this private preview.

Dependency folders, Git history, local caches and compiled build output are excluded. These are recreated by installing and building. All site assets are included in public/assets.
